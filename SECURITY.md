# Security Policy

Security fixes are supported for the latest released zio line. Pre-release
versions receive fixes on a best-effort basis until the first stable release.

Report a vulnerability privately through this repository's GitHub security
advisory interface. If private reporting is unavailable, contact the maintainer
listed in `Cargo.toml` to request a private channel; do not publish exploit
details in an issue.

Include the affected version or commit, platform, impact, and the smallest
reproducer you can safely share. Please allow time for acknowledgement,
triage, coordinated remediation, and release before public disclosure.
